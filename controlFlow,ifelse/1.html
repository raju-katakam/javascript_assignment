What is control flow in JavaScript? Explain how if-else statements work withan example.? Ans:Control flow in JavaScript is the order in which the program’s statements are executed. By default, JavaScript runs code top to bottom, but control flow statements let you change that order based on conditions, loops, or decisions. Common control flow tools include: if, else if, else switch loops (for, while) break, continue, return Ex: let age = 18; if (age >= 18) { console.log("You are eligible to vote."); } else { console.log("You are not eligible to vote."); }

Explain the concept of state in React and how it is used to manage component data Ans: State in React is an object that stores dynamic data of a component and controls how the component behaves and renders. It allows components to update and re-render automatically when data changes. In simple words, state is used to manage changing data inside a component. Key Points of State State is mutable (can change over time) State is managed inside the component When state changes, the component re-renders automatically Used to store dynamic data like: form inputs counters user data API responses UI changes Example: State in Functional Component import React, { useState } from "react"; function Counter() { const [count, setCount] = useState(0); return (

Count: {count}

); } export default Counter; Explanation useState(0) → initializes state with value 0 count → current state value setCount() → function to update state When button is clicked → state updates → component re-renders Output: Count: 0 Increase button Click button → Count becomes 1, 2, 3...

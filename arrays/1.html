What is an array in JavaScript? How do you declare and initialize an array? Ans:An array in JavaScript is a data structure used to store multiple values in a single variable. These values can be of any data type (numbers, strings, objects, even other arrays), and each value is stored at a numeric index starting from 0. Declaring an Array Using Array Literals (most common & recommended) let fruits = []; Using the Array Constructor let fruits = new Array(); Initializing an Array Initialize with values let fruits = ["Apple", "Banana", "Mango"];

What is the difference between a while loop and a do-while loop? Ans:The key difference comes down to when the condition is checked. while loop Condition is checked first The loop may run zero times if the condition is false at the start let i = 1; while (i <= 3) { console.log(i); i++; } If i started at 5, this loop wouldn’t run at all. do...while loop Condition is checked after the loop body The loop always runs at least once, even if the condition is false let i = 5; do { console.log(i); i++; } while (i <= 3); This prints 5 one time, even though i <= 3 is false.

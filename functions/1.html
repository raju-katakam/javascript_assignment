What are functions in JavaScript? Explain the syntax for declaring and calling a function? Ans:Functions in JavaScript are reusable blocks of code that perform a specific task. Instead of writing the same code again and again, you put it inside a function and call it whenever needed. This makes code cleaner, reusable, and easier to maintain. Ex: function add(a, b) { return a + b; } add(2,3); function without parameteres: function greet() { console.log("Hello, Welcome!"); } greet();

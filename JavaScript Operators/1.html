Operators: JavaScript operators are symbols used to perform operations on values and variables. Common types include Arithmetic, Assignment, Comparison, and Logical operators. 1.Arithmetic Operators Used to perform mathematical calculations. + Addition 10 + 5 → 15 - Subtraction 10 - 5 → 5 * Multiplication 10 * 5 → 50 / Division 10 / 5 → 2 % Modulus (remainder) 10 % 3 → 1 ++ Increment let a=5; a++; → 6 -- Decrement let b=5; b--; → 4 ex: let a = 10; let b = 3; console.log(a + b); // 13 console.log(a % b); // 1 2.Assignment Operators Used to assign values to variables. Operator Meaning Example = Assign x = 10 += Add and assign x += 5 -= Subtract and assign x -= 5 *= Multiply and assign x *= 5 /= Divide and assign x /= 5 ex: let x = 10; x += 5; // x = x + 5 console.log(x); // 15 3.Comparison Operators Used to compare two values. Result is true or false. == Equal (value only) 5 == "5" → true === Strict equal (value + type) 5 === "5" → false != Not equal 5 != 3 → true !== Strict not equal 5 !== "5" → true > Greater than 10 > 5 < Less than 5 < 10 >= Greater than or equal 10 >= 10 <= Less than or equal 5 <= 10 ex: let a = 5; let b = "5"; console.log(a == b); // true console.log(a === b); // false 4.Logical Operators Used to combine multiple conditions. && AND (a > 5 && b < 10) ! NOT !true → false ex: let age = 25; let hasId = true; if (age >= 18 && hasId) { console.log("Allowed"); } else { console.log("Not Allowed"); }

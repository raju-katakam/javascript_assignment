What is the role of render() in class components? Ans: In React class components, the render() method plays a very important role. Role of render() in Class Components The render() method is responsible for returning the JSX (UI) that should be displayed on the screen. Key Points Mandatory in class components Every class component must include a render() method. Returns JSX The render() method returns JSX that describes what should appear in the UI. Pure Function It should not modify state directly or perform API calls. It only returns UI based on props and state. Re-renders on state/props change When state or props change, React automatically calls render() again to update the UI.

What is JSX in React.js? Why is it used? Ans: JSX (JavaScript XML) is a syntax extension for JavaScript used in React to write HTML-like code inside JavaScript. It makes it easier to create and manage UI components. JSX allows developers to write UI structure in a readable and simple way instead of using complex React.createElement() functions.
